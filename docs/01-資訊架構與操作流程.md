# 01 資訊架構與操作流程

對應需求書「十二、第一個開發任務」第 1～6 項。

## 1. 網站整體資訊架構

設計原則：手機優先、底部五個分頁、每頁一個主要動作、字級可調（18 / 20 / 22 px）、觸控目標 48 px 以上。

```
/login                     登入（ChatGPT 登入；第一階段另提供示範身分）
│
├─ 學員（底部導覽：首頁・作業・教材・分享・我的）
│  ├─ /                    首頁：下一次聚集、待辦（表單＋作業，含截止提示）、老師回覆、我的小組、最新教材、最近分享
│  ├─ /courses, /courses/[id]   我的課程 → 課程詳情（教材、表單、作業）
│  ├─ /forms, /forms/[id]       線上表單：待填寫／已完成 → 填寫、草稿、修改、歷史、老師回覆
│  ├─ /assignments, /assignments/[id]   作業：個人／分組 → 內容、繳交、版本紀錄、批改結果
│  ├─ /group               我的小組：組員、組長、小組作業狀態、異動紀錄
│  ├─ /materials, /materials/[id]       教材中心（依課程、類型篩選）→ 預覽／下載
│  ├─ /articles, /articles/[id], /articles/new   文章分享、留言、發布（可見範圍）
│  ├─ /notifications       通知
│  └─ /me                  我的：學習進度、字級、登出
│
└─ 老師／助教／管理員（底部導覽：後台・作業・表單・分享・我的；桌面側欄列出全部）
   ├─ /admin               後台總覽：學員數、待批改、填寫率、完成率、待處理、最新提交、操作紀錄
   ├─ /admin/courses       課程
   ├─ /admin/forms, /admin/forms/new, /admin/forms/[id]   表單建立（7 種題型）、學員回答、題目統計、整份／個別題目回覆、提醒未填
   ├─ /admin/assignments, /admin/assignments/new, /admin/assignments/[id]   作業發布（個人／分組、期限、格式、大小、補交、重交、批改方式）、繳交狀態、批改
   ├─ /admin/materials     教材上傳（PDF、Word、簡報、圖片、音訊、影片連結）、課前閱讀置頂
   ├─ /admin/groups        小組管理：新增、改名、組員、組長、完成情況、異動紀錄（保留歷史）
   ├─ /admin/users         帳號：建立、角色、停用（限管理員）
   └─ /admin/stats         統計：作業／表單／學員／小組／課程完成率、圖表、Excel 匯出（範圍、匿名）
```

角色權限：

| 功能 | 學員 | 助教 | 老師 | 管理員 |
| --- | --- | --- | --- | --- |
| 填表單、交作業、看教材、分享文章 | ✔ | ✔ | ✔ | ✔ |
| 建立表單／作業、上傳教材 | | ✔（授權範圍） | ✔ | ✔ |
| 批改、回覆 | | ✔（協助） | ✔ | ✔ |
| 統計、匯出 | | ✔（授權範圍） | ✔ | ✔ |
| 小組管理 | | | ✔ | ✔ |
| 帳號與角色 | | | | ✔ |

第一階段以前端 `StaffOnly` 做頁面保護；第二階段起所有授權在 Workers 端重新檢查。

## 2. 主要頁面配置

**手機（< 768px）**：頂欄（頁名、字級切換、通知鈴）＋內容＋固定底部五分頁。表單與作業頁的「暫存／送出」固定在底部導覽上方，隨時可按。

**桌面（≥ 768px）**：左側 256px 固定側欄列出全部功能；內容區學員頁最寬 768px（閱讀舒適），後台最寬 1152px（表格與左右雙欄：左邊學員清單、右邊回答／批改）。

共用模式：

- 清單列（icon＋標題＋副標＋狀態徽章＋箭頭），手機上狀態徽章換到標題下方。
- 截止提示三級：灰（一般）、琥珀（3 天內／今天）、磚紅（已逾期），逾期的列加框線強調。
- 繳交狀態與批改狀態為兩個獨立徽章（尚未繳交／草稿／已繳交／逾期繳交／已重新繳交；待批改／批改中／已批改／需要修改）。

## 3. 學員操作流程

1. 開啟 LINE 群組中的連結 → `/login` → Sign in with ChatGPT（或示範身分）。
2. 首頁看到「下一次聚集」與待辦（最急的在最上面，顯示截止日）。
3. 課前：點「第六課簡報（課前閱讀）」閱讀 → 填「第六課 課前預備」表單（可暫存草稿，之後再送出）。
4. 課後：填「課後回饋問卷」→ 交個人作業 → 與小組討論後由一位組員代表提交分組作業。
5. 收到「老師回覆」或「作業已批改」通知 → 點進查看評語；需要修改時直接重新提交。
6. 隨時在「分享」發布見證或資源、留言互動；在「我的」查看進度與調整字級。

## 4. 老師操作流程

1. 課前兩週：後台 → 教材管理 → 上傳簡報並勾「課前閱讀」→ 系統通知全體學員。
2. 建立「課前預備」表單（表單 → 建立表單 → 選題型 → 設定開放／截止 → 建立並發布）。
3. 課後：建立課後回饋問卷、發布個人作業與分組作業（可指定小組）。
4. 後台總覽看填寫率／繳交率 → 表單頁「提醒未填寫的 N 位學員」；作業頁「提醒未繳交」。
5. 批改：作業頁左側點學員或小組 → 預覽／下載附件 → 分數＋評語 → 完成批改或要求重新提交（整組共同回覆）。
6. 回覆表單：針對整份或個別題目留言；可看學員是否已讀。
7. 聚集前：統計頁看各小組完成率、表單題目統計；匯出 Excel 給同工。

## 5. 個人作業繳交流程

```
老師發布（個人）──► 每位學員各自看到「尚未繳交」
                        │ 輸入文字／上傳檔案／貼連結（可混用）
                        ├─ 暫存草稿 ──► 狀態「已儲存草稿」
                        └─ 正式提交 ──► 第 1 版，狀態「已繳交」（逾期則「逾期繳交」）
                                       批改狀態「待批改」
老師批改 ──► 分數／評語 ──► 「已批改」並通知
        └─ 要求重新提交 ──► 「需要修改」──► 學員提交第 2 版 ──► 「已重新繳交」＋「待批改」
```

系統記錄：學員、作業、每一版的提交時間與內容、附件、批改者與時間、學員是否已讀。繳交狀態與批改狀態分開儲存，不互相覆蓋。

## 6. 分組作業繳交流程

```
老師建立小組（組員、組長）
老師發布（分組，可指定小組）──► 該組所有組員都看到同一份作業與狀態
任一組員（不限組長）
   ├─ 暫存草稿 ──► 其他組員可接續編輯（顯示「由誰在何時儲存」）
   └─ 代表提交 ──► 系統記錄實際提交者 ──► 整組狀態「已繳交」，並通知所有組員
老師批改 ──► 整組共同評分／回覆 ──► 所有組員都看到
允許重新提交時 ──► 任一組員提交第 N 版，保留所有版本與提交者
```

多人同時提交的衝突處理：每個提交紀錄有 `version`（樂觀鎖）。提交時帶上畫面載入時的版本；若已被其他組員更新，系統拒絕並提示「其他組員剛剛已經提交了新版本，請先查看最新內容」，不會覆蓋。第二階段在 D1 以 `UPDATE … WHERE version = ?` 實作同一規則。

小組名單變更：`group_members` 以加入／離開時間記錄歷史，已提交的作業綁定小組與實際提交者，不因組員異動而遺失。
