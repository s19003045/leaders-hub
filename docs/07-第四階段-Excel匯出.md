# 07 第四階段：Excel 匯出（ExcelJS）

完成日期：2026-11-01。

## 產出

後台「統計與匯出 → 匯出」下載一個 `.xlsx`，含 8 個工作表（對應需求書第八章）：

| # | 工作表 | 內容 | 特色 |
| --- | --- | --- | --- |
| 1 | 表單原始回答 | 每人每題一列 | 自動篩選、凍結首列 |
| 2 | 個人作業繳交紀錄 | 狀態、版本數、分數、評語 | |
| 3 | 分組作業繳交紀錄 | 小組、實際提交者、評語 | |
| 4 | 各學員完成率 | 表單／個人／分組完成數與整體完成率 | 完成率欄 data bar |
| 5 | 各小組完成率 | 組長、完成率 | data bar |
| 6 | 各課程完成率 | 作業數、表單數、完成率 | data bar |
| 7 | 表單題目統計 | 單選／多選各選項人數、評分平均與分布、文字回答數 | |
| 8 | 統計圖表 | 四張圖表的數值表＋嵌入 PNG 圖（作業完成率、表單填寫率、各小組、各課程）＋匯出說明 | 圖片 |

匯出選項：課程範圍、指定作業、提交時間起迄、匿名（以「學員01」取代姓名）。資料來源是使用者自己取得的快照，因此自然遵守伺服器端的存取裁切（助教／老師／管理員才看得到此頁）。

## 設計決定

- **圖表用圖片**：ExcelJS 不支援建立 Excel 原生圖表物件（只能保留既有圖表）。因此在瀏覽器以 Canvas 繪製水平長條圖（`lib/charts-png.ts`，2 倍解析度）後以 `workbook.addImage` 嵌入第 8 張工作表；完成率欄位另加 Excel 內建的 data bar，在 Excel 裡仍是可讀的數值條。
- **在瀏覽器端產生**：Workers 記憶體 128 MB 且要避免長時間請求；匯出資料量小（15 人），在前端組檔最單純。`exceljs` 以動態 `import()` 載入，不進入首頁 bundle。
- **CSV 備援**：按「改下載 CSV」仍可一表一檔（含 BOM）。

## 檔案

- `lib/export.ts`：8 張表的資料整理、圖表資料、篩選條件。
- `lib/export-xlsx.ts`：ExcelJS 組檔（樣式、欄寬、篩選、data bar、圖片、匯出說明）。
- `lib/charts-png.ts`：Canvas 長條圖 → PNG。
- `components/export-panel.tsx`：匯出 UI 與預覽。
- `scripts/export-check.mjs`：Node 端驗證（`pnpm check:export`）。

## 已驗證

- `pnpm check:export`：8 個工作表、57 列表單回答、12 位學員、3 組、第 8 張嵌入 4 張圖片；指定課程、匿名、指定作業、時間範圍四種篩選正確。
- 瀏覽器：產生 144 KB 的 `.xlsx`（ZIP 簽章 PK，含 `xl/media/image1.png`），下載觸發。

## 之後可做

- 若需要 Excel 原生圖表，可改在伺服器端以 Python openpyxl 產生（需另一個服務），或在匯出後用 Excel 的「插入圖表」對第 8 張工作表的數值表操作。
