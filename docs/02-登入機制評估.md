# 02 登入機制評估（ChatGPT / Google / LINE）

研究日期：2026-11-01。來源：ChatGPT Sites 官方文件（learn.chatgpt.com/docs/sites/*，由 developers.openai.com/codex/sites 轉址）、Sign in with ChatGPT 開發者文件、附件 BBQ Together 專案原始碼。

## 結論

| 方案 | 可行性 | 說明 |
| --- | --- | --- |
| Sign in with ChatGPT | **確定可行（官方內建）** | 使用者需要 ChatGPT 帳號（免費帳號即可，可用 Google 帳號註冊）。 |
| Google 登入 | **未經 Sites 官方驗證** | 文件只提到「外部身分提供者」需要「啟用驗證的網站」，未說明支援哪些提供者或如何設定。技術上可在 Workers 內自行實作 OIDC（HTTP 可行），但網站必須設為「公開」，再由應用程式自己做會員登入。 |
| LINE 登入 | **同上** | LINE Login 走標準 OAuth 2.0 / OIDC，可與 Google 相同方式自行實作；同樣需要網站公開。 |

**建議：第一版使用 Sign in with ChatGPT**，原因：

1. 官方唯一保證可用的機制，不需自己保管密鑰、處理 session。
2. 12～15 位成員，請大家建立 ChatGPT 帳號的成本低（可用 Google 帳號一鍵註冊），且上課本身也在推動 AI 工具使用。
3. 管理員只需在「學員帳號」填入成員的 ChatGPT 登入 Email，系統以 Email 對應身分與角色。

Google / LINE 登入列為第三階段選項：若確認 Sites 允許公開網站＋自訂 OAuth，再加上 LINE Login（成員最熟悉）。

## 官方文件確認的事實

- 登入／登出連結由平台提供：`/signin-with-chatgpt?return_to=…`、`/signout-with-chatgpt`。
- 登入後每個請求帶 header：`oai-authenticated-user-email`（保證有值）、`oai-authenticated-user-full-name`（可能為空，需以 Email 為後備）。附件專案另讀取 `oai-authenticated-user-id`，官方文件未列出，本專案在缺少時以 Email 作為穩定鍵（`lib/chatgpt-auth.ts`）。
- 授權判斷要放在伺服器端程式碼。
- 網站存取範圍：僅擁有者與管理員 → 指定使用者／群組 → 邀請外部檢視者（Plus/Pro/Business/Enterprise 逐步開放）→ 工作區全體 → 網際網路公開（需啟用公開發佈）。受限分享時，訪客必須以收到邀請的帳號登入。
- 「公開網站可以維持對所有人開放，同時提供選用的 Sign in with ChatGPT」。
- 平台提供 D1（10 GB／站）、R2（無固定上限）、環境變數與密鑰（在 Sites 設定頁管理）。
- 執行環境支援 HTTP/HTTPS/WebSocket，不支援原始 TCP；不支援背景常駐服務（排程推播需另想辦法，見 03 文件）。

## 本專案的登入設計

```
正式環境                               第一階段（本機／示範）
瀏覽器 → /signin-with-chatgpt          登入頁「示範身分」直接選擇
      → Sites 完成 OAuth               （或 Vite 外掛模擬 seedy@sites.test）
      → 每個請求帶 oai-authenticated-*  
      → /api/me 讀 header               /api/me 讀 header（本機為模擬帳號）
      → users.email 對應 → 角色          localStorage 記住目前身分
```

第二階段實作重點：

1. `users` 表以 `email` 唯一；首次登入時將 `chatgpt_user_id` 綁定到該列，之後以 id 為準（Email 變更時仍可對應）。
2. 不在名單中的 Email → 顯示「請聯絡管理員」，不自動建立帳號（避免群組外的人加入）。
3. `INITIAL_ADMIN_EMAIL` 環境變數指定第一位管理員，之後由管理員在後台新增其他帳號。
4. 若日後改公開網站＋自訂 OAuth：登入狀態以 HttpOnly cookie 保存，密鑰只放 Sites 環境變數，回呼網址需在 Google Cloud Console / LINE Developers 註冊網站正式網域。
