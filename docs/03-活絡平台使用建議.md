# 03 活絡平台使用建議

問題：只把連結貼在 LINE 群組，成員感受不到平台的變化；LINE 群組太多，原群組也會被淹沒。
原則：**不要求成員「記得來看」，而是讓平台主動、適量地去找他們；每次來都有事可做、有人回應。**

## A. 通知要到 LINE 裡，而不是只在平台裡

成員每天打開的是 LINE，不是網站。平台每個重要事件都應該變成一則 LINE 訊息，並附「一鍵直達」連結：

| 事件 | 訊息範例 | 連結 |
| --- | --- | --- |
| 新教材（課前閱讀） | 「第六課簡報已上傳，11/14 上課前請先看完（約 15 分鐘）」 | `/materials/[id]` |
| 表單／作業截止前 3 天與當天 | 「課後回饋還有 3 天截止，目前 8/12 人完成」 | `/forms/[id]` |
| 老師回覆、作業批改 | 「張老師回覆了你的第五課回饋」 | `/forms/[id]` |
| 小組作業被組員提交 | 「淑芬代表第一組交了作業，看看內容」 | `/assignments/[id]` |
| 有人分享文章 | 「國強分享了一篇見證：誠信實驗」 | `/articles/[id]` |

實作方式（第三階段）：

1. **LINE Messaging API（官方帳號）**：建立一個免費的 LINE 官方帳號，成員加好友後可以「推播給個人」（個人通知，如老師回覆）與「推播到群組」（公告，如新教材）。免費方案每月 200 則，對 15 人夠用；超過可改用「回覆訊息」節省額度。Workers 可直接呼叫 HTTPS API，Sites 文件確認 HTTP 對外連線可用。
2. **LINE Notify 已於 2025 年停止服務**，請勿規劃。
3. **排程提醒**：Sites 不支援背景服務，截止前提醒改用「有人開啟網站時順便檢查是否該發提醒」的惰性排程（記錄最後檢查時間，每小時最多跑一次），或由管理員在後台按「發送提醒」。
4. 訊息要短、有名字、有數字（「8/12 人完成」會產生正向同儕壓力）。

## B. 首頁要像「今天的待辦」，不是「功能列表」

已在原型實作：登入後第一眼就是「你有 2 件待辦」、下一次聚集日期、未讀的老師回覆。沒有待辦時顯示感謝語，不要空白。

## C. 讓老師與助教的回應成為最大的吸引力

成年人回到平台的最大動力是「有人回應我寫的東西」。

- 老師／助教承諾：表單送出後 **3 天內** 至少一句回覆（原型已支援整份或單題回覆、已讀狀態）。
- 後台總覽列出「未回覆」的表單與「待批改」的作業，助教每週固定清一次。
- 批改時用「要求重新提交」而不是扣分，營造對話而非考試。

## D. 小組機制當作社交引擎

- 分組作業由「任一組員」提交並通知全組，讓組員之間互相提醒（原型已實作，含實際提交者紀錄）。
- 小組頁顯示各組完成狀況；統計頁的「各小組完成率」可在聚集時公開表揚，但不公開個人未交名單。
- 組長在截止前 2 天收到一則「你的組還沒交」的個人訊息，由組長在 LINE 小群裡催，比老師催有效。

## E. 內容節奏：每兩週有一件新東西

課程兩個月一次，間隔太長平台會冷掉。建議固定節奏：

| 週次 | 內容 |
| --- | --- |
| 課後第 1 週 | 課後回饋問卷、課程錄音上架 |
| 課後第 2～3 週 | 個人作業截止、老師回覆 |
| 課後第 4～5 週 | 小組作業截止、老師分享一篇文章（見證、禱告焦點） |
| 課前 2 週 | 下一課簡報（課前閱讀）、課前預備表單 |
| 課前 1 週 | 預備提醒、小組討論時間確認 |

助教每週一在「分享」貼一篇短文（推薦書、一句經文、上週某位成員的行動進展），讓平台「有人在」。

## F. 上線頭兩個月的啟動方法

1. **在聚集現場一起登入**：11/14 第六課用 10 分鐘，大家當場用 ChatGPT 帳號登入、填一份兩題的表單、看到老師當場回覆。第一次成功體驗最重要。
2. **把 LINE 群組的固定動作搬過來**：往後簡報、問卷只放平台，LINE 群只放「連結＋一句話」；不要兩邊都放，否則平台永遠是備用品。
3. **LINE 群組置頂訊息**放平台連結與「怎麼登入」三步驟。
4. **手機加到主畫面**：原型已設定 viewport 與主題色，iPhone「加入主畫面」後像 App；教大家做一次。
5. 前兩個月由助教每週回報「本週 12 人中有 10 人登入」，讓老師看得到成效並公開感謝。

## G. 未來可加的小機制（第四階段後）

- 個人「行動承諾」卡：填表單時勾選的行動（原型第五課問卷第 3 題）在下次聚集前提醒本人「你說要做的事做了嗎？」。
- 年度回顧頁（第七課）：自動整理每人一年來的回答與作業，做成一頁可下載的「我的 2026 職場轉化紀錄」。
- 簡單的「我讀過了」按鈕：教材頁一鍵回報已閱讀，老師課前就知道誰讀過簡報。
